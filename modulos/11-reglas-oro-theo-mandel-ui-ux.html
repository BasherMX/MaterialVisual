Las 3 Reglas de Oro
de Theo Mandel (UI/UX)

Fundamentos esenciales del diseño de interfaz de usuario según la doctrina de Pressman. Experimenta cómo el control del usuario, la reducción de carga cognitiva y la consistencia operativa transforman una interfaz ordinaria en un sistema profesional.

🏆 Doctrina de Theo Mandel y Roger Pressman

Regla de Oro Principio Central Directrices Clave de Diseño Impacto en la Experiencia
1. Dar el control al usuario
Place user in control		 El usuario es el piloto: no forzar secuencias inflexibles ni caminos sin retorno. • Permitir deshacer (undo) y rehacer (redo).
• Evitar secuencias modales rígidas.
• Confirmar antes de acciones destructivas.
• Permitir pausar o interrumpir procesos. 		Otorga libertad, elimina la frustración y disipa el temor a cometer errores irreparables.
2. Reducir carga de memoria
Reduce memory load		 No obligar al usuario a memorizar datos entre pantallas o pasos previos. • Ofrecer valores por defecto razonables.
• Reconocimiento sobre recuerdo (metáforas del mundo real).
• Relleno automático y atajos intuitivos.
• Divulgación progresiva de información compleja. 		Acelera la toma de decisiones y mantiene despejada la memoria de trabajo cognitiva.
3. Hacer la interfaz consistente
Make interface consistent		 Uniformidad estructural, estética y operativa a lo largo de todo el sistema. • Misma terminología y posicionamiento de botones.
• Respuestas y atajos idénticos ante acciones similares.
• Jerarquía cromática y tipográfica estandarizada.
• Patrones de navegación unificados. 		Facilita la transferencia de aprendizaje; dominar una pantalla es dominar todo el sistema.

📋 Auditoría de Principios UI

  • 1. Place user in control El software debe obedecer el ritmo humano: botones de deshacer, flujos flexibles y confirmación explícita para evitar pérdidas catastróficas.
  • 2. Reduce user's memory load La regla de los 7±2 elementos de Miller demuestra que la mente se satura fácilmente. Deja que la máquina recuerde los datos y el usuario reconozca opciones.
  • 3. Make interface consistent La ley del menor esfuerzo cognitivo: si una acción se ejecuta de cierta manera aquí, debe ejecutarse idénticamente en todo el ecosistema.
