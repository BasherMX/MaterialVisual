Estructuras de Datos · Osvaldo Cairó

Direccionamiento de Memoria en Matrices $A[m \times n]$

Cómo el hardware y los compiladores proyectan estructuras bidimensionales sobre la memoria RAM física lineal. Fórmulas canónicas de mapeo por Renglones (Row-Major) y Columnas (Column-Major), cálculo de offsets y tamaño de palabra ($w$).

1. El Problema del Mapeo 2D a Memoria 1D

En la obra clásica Estructuras de Datos de Osvaldo Cairó, se establece una premisa arquitectónica fundamental: la memoria física de una computadora es estrictamente lineal y unidimensional (una secuencia contigua de bytes con direcciones enteras consecutivas: $0, 1, 2, 3, \dots$).

La Matriz Lógica $A[m \times n]$

Una matriz consta de $m$ renglones (filas) y $n$ columnas. Cada elemento individual se designa como $A[i, j]$, donde:

  • $i$ es el índice de renglón ($1 \le i \le m$ en base 1; $0 \le i < m$ en base 0).
  • $j$ es el índice de columna ($1 \le j \le n$ en base 1; $0 \le j < n$ en base 0).
  • Total de elementos en la matriz: $m \times n$.

Variables de Direccionamiento Físico

Para calcular la posición física en memoria se emplean cuatro parámetros canónicos:

  • $POSINI$ (o DirBase): Dirección de memoria donde reside el primer elemento de la matriz ($A[1, 1]$ o $A[0, 0]$).
  • $w$ (Word Size): Número de bytes o palabras que ocupa cada elemento del tipo de dato (ej. int = 4 bytes, double = 8 bytes).
  • $m$: Número total de renglones declarados en la matriz.
  • $n$: Número total de columnas declaradas en la matriz.

¡Trampa Clásica de Examen de Oposición! (Base 1 vs Base 0)

En los libros teóricos de algoritmos y reactivos del SPC (Cairó, Sedgewick, Knuth), los arreglos suelen expresarse con índices base 1 ($1 \le i \le m$, $1 \le j \le n$). En C#, C++, Java y Python se usa base 0.

Si no restas el $-1$ en fórmulas base 1, tu dirección tendrá un desplazamiento erróneo. En este módulo analizamos ambas con énfasis en la doctrina de Cairó (Base 1).

Criterio Row-Major Order (Por Renglones) Column-Major Order (Por Columnas)
Disposición en RAM Se almacena el Renglón 1 completo, luego Renglón 2, etc. Se almacena la Columna 1 completa, luego Columna 2, etc.
Lenguajes que lo adoptan C, C++, C#, Java, Python, Rust, Pascal Fortran, MATLAB, R, Julia
Dimensión Crítica Requiere conocer $n$ (número de columnas) Requiere conocer $m$ (número de renglones)
Fórmula Base 1 ($LOC$) POSINI + [n*(i - 1) + (j - 1)] * w POSINI + [m*(j - 1) + (i - 1)] * w

2. Direccionamiento por Renglones (Row-Major Order)

En el orden por renglones, los elementos de la matriz se guardan secuencialmente en la memoria fila por fila. Para acceder a un elemento en el renglón $i$ y columna $j$, debemos:

  1. Saltar todos los renglones previos completos: hay $(i - 1)$ renglones anteriores.
  2. Cada renglón contiene exactamente $n$ columnas (elementos). Por tanto, se saltan $(i - 1) \times n$ celdas.
  3. Dentro del renglón actual $i$, nos desplazamos $(j - 1)$ columnas hacia adelante.
  4. Multiplicar el total de celdas saltadas por el tamaño de palabra $w$ y sumarlo a $POSINI$.

Fórmula de Osvaldo Cairó (Row-Major · Base 1)

LOC(A[i, j]) = POSINI + [ n × (i − 1) + (j − 1) ] × w

* Nota: La cantidad total de renglones ($m$) NO interviene en el cálculo de la dirección; sólo importa $n$ (el ancho de cada renglón).

Ejemplo Numérico Canónico SPC

Sea una matriz $A[4 \times 5]$ de números enteros (4 bytes por elemento, $w = 4$), almacenada a partir de la dirección $POSINI = 1000$. Calcular la dirección física de $A[3, 4]$ por renglones:

Datos:
m = 4, n = 5, POSINI = 1000, w = 4
Buscamos elemento: i = 3, j = 4

Paso 1: Renglones completos previos = (i - 1) = 3 - 1 = 2
Paso 2: Celdas en renglones previos = 2 * n = 2 * 5 = 10 celdas
Paso 3: Celdas en renglón actual = (j - 1) = 4 - 1 = 3 celdas
Paso 4: Total de celdas previas = 10 + 3 = 13 celdas
Paso 5: Desplazamiento en bytes = 13 * 4 = 52 bytes
Paso 6: LOC(A[3, 4]) = 1000 + 52 = 1052

Variante en Base 0 (C#, C, C++)

Si los índices van desde $0$ hasta $m-1$ y $0$ hasta $n-1$:

Fórmula Base 0:
LOC(A[i, j]) = POSINI + [ n × i + j ] × w

Para el mismo tercer renglón y cuarta columna lógica (i=2, j=3):
Offset = (5 * 2 + 3) * 4 = (10 + 3) * 4 = 52
LOC = 1000 + 52 = 1052 ✓

Observa cómo ambas fórmulas convergen exactamente en la misma celda física.

3. Direccionamiento por Columnas (Column-Major Order)

En el orden por columnas, los elementos se guardan columna por columna en la memoria continua. Este es el formato estándar en Fortran, MATLAB y bibliotecas de álgebra lineal de alto rendimiento (BLAS, LAPACK).

Fórmula de Osvaldo Cairó (Column-Major · Base 1)

LOC(A[i, j]) = POSINI + [ m × (j − 1) + (i − 1) ] × w

* Aquí el factor crítico es $m$ (total de renglones), pues cada columna completa mide $m$ elementos de alto.

Ejemplo Numérico Canónico SPC (Columnas)

Misma matriz $A[4 \times 5]$, $w = 4$ bytes, $POSINI = 1000$. Calcular la dirección física de $A[3, 4]$ por columnas:

Datos:
m = 4, n = 5, POSINI = 1000, w = 4
Buscamos elemento: i = 3, j = 4

Paso 1: Columnas completas previas = (j - 1) = 4 - 1 = 3
Paso 2: Celdas en columnas previas = 3 * m = 3 * 4 = 12 celdas
Paso 3: Celdas en columna actual = (i - 1) = 3 - 1 = 2 celdas
Paso 4: Total de celdas previas = 12 + 2 = 14 celdas
Paso 5: Desplazamiento en bytes = 14 * 4 = 56 bytes
Paso 6: LOC(A[3, 4]) = 1000 + 56 = 1056

Comparación Crítica de Resultados

Elemento Row-Major ($n=5$) Column-Major ($m=4$)
$A[1, 1]$ 1000 1000
$A[1, 2]$ 1004 1016 (salta 4 celdas)
$A[2, 1]$ 1020 (salta 5 celdas) 1004
$A[3, 4]$ 1052 1056
$A[4, 5]$ (Fin) 1076 1076

El primer ($A[1, 1]$) y el último ($A[m, n]$) elemento siempre comparten exactamente la misma dirección física; los elementos intermedios divergen completamente según el orden de almacenamiento.

5. Laboratorio de Evaluación SPC · Direccionamiento de Arreglos

Resuelve estos 4 reactivos de alta complejidad con base en la bibliografía oficial de Osvaldo Cairó y evaluaciones técnicas del Servicio Profesional de Carrera (INEGI).

1. Sea una matriz $A[5 \times 6]$ almacenada por renglones (Row-Major) en base 1, con $POSINI = 1000$ y cada elemento ocupando $w = 2$ bytes. ¿Cuál es la dirección de memoria física de $A[4, 3]$?

Explicación:
Fórmula: $LOC = POSINI + [n(i - 1) + (j - 1)] \times w$.
$n = 6$, $i = 4$, $j = 3$, $w = 2$, $POSINI = 1000$.
Desplazamiento = $[6 \times (4 - 1) + (3 - 1)] \times 2 = [6 \times 3 + 2] \times 2 = [18 + 2] \times 2 = 20 \times 2 = 40$.
$LOC = 1000 + 40 = 1040$.

2. Si la misma matriz anterior $A[5 \times 6]$ ($POSINI = 1000$, $w = 2$) fuera almacenada en orden por columnas (Column-Major) en base 1, ¿cuál sería la dirección de $A[4, 3]$?

Explicación:
Fórmula: $LOC = POSINI + [m(j - 1) + (i - 1)] \times w$.
$m = 5$, $i = 4$, $j = 3$, $w = 2$, $POSINI = 1000$.
Desplazamiento = $[5 \times (3 - 1) + (4 - 1)] \times 2 = [5 \times 2 + 3] \times 2 = [10 + 3] \times 2 = 13 \times 2 = 26$.
$LOC = 1000 + 26 = 1026$.

3. Al calcular la dirección física de un elemento en un arreglo bidimensional almacenado por renglones (Row-Major), ¿por qué el número de renglones totales ($m$) es irrelevante para la función de direccionamiento?

Explicación:
En Row-Major, para saltar los $(i-1)$ renglones previos, la única información de ancho necesaria es el número de elementos por fila ($n$). El límite total $m$ sirve para validar que no haya desbordamiento de índice (bounds checking), pero no participa en la aritmética del offset.

4. En una matriz $A[m \times n]$, ¿qué elementos tienen garantizada exactamente la misma dirección de memoria tanto en Row-Major como en Column-Major?

Explicación:
El primer elemento ($A[1, 1]$) tiene offset 0 en ambos esquemas ($LOC = POSINI$). El último elemento ($A[m, n]$) tiene siempre un offset de $(m \times n - 1) \times w$ bytes, pues independientemente de cómo se ordenen internamente las celdas, ambos esquemas deben recorrer la totalidad de las celdas anteriores antes de alcanzar la última.
