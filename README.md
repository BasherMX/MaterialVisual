# MaterialVisual

🚀 **Sitio en vivo:** https://bashermx.github.io/MaterialVisual/

Visualizadores y simuladores interactivos de estructuras de datos, algoritmos, diseño de software, bases de datos y gestión de proyectos:
- 01. Árboles AVL y autobalanceo
- 02. Recorridos BFS vs DFS en grafos
- 03. Complejidad Computacional (Big O)
- 04. Paradigmas: Greedy vs Divide & Conquer
- 05. Fundamentos de Programación Orientada a Objetos (POO)
- 06. Las 3 Reglas de Oro de Theo Mandel para UI/UX (Roger Pressman)
- 07. Modelado Conceptual ERD y Notaciones de Diagramas (Chen, Pata de Gallo, IDEF1X, UML)
- 08. Diseño Lógico Relacional y Normalización (1FN, 2FN, 3FN, BCNF y Desnormalización)
- 09. El Triángulo de Hierro: Triple Restricción de Proyectos (Sommerville & Pressman)
