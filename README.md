# MaterialVisual

🚀 **Sitio en vivo:** https://bashermx.github.io/MaterialVisual/

Visualizadores y simuladores interactivos de estructuras de datos, algoritmos y diseño de software:
- Árboles AVL y autobalanceo
- Recorridos BFS vs DFS en grafos
- Complejidad Computacional (Big O)
- Paradigmas: Greedy vs Divide & Conquer
- Fundamentos de Programación Orientada a Objetos (POO)
- Las 3 Reglas de Oro de Theo Mandel para UI/UX (Roger Pressman)
